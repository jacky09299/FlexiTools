開發者指南

歡迎加入 FlexiTools 開發行列。
這份文件將引導您從環境建置到模組開發的完整流程。

目錄
1. 環境建置 2. 專案結構 3. 模組開發 4. 多語言支援 5. 建置與打包 6. 提交貢獻

1. 環境建置

FlexiTools 基於 Python 3.9+ 與 Tkinter 構建。我們建議使用 Conda 來管理開發環境。

1安裝 Miniconda

請前往 Miniconda 官網下載並安裝適用於您作業系統的版本。

2建立環境

在專案根目錄執行以下指令以建立名為 tools 的虛擬環境：

conda create -n tools python=3.9
conda activate tools
3安裝依賴

專案依賴許多第三方套件以支援不同模組的功能：

pip install pandas matplotlib PyPDF2 moviepy opencv-python rembg cefpython3 psutil pygame pyroomacoustics yt-dlp

提示：您可以執行 python check_imports.py 來檢查環境是否缺漏套件。

2. 專案結構

了解專案目錄結構有助於您快速定位檔案。

modules/

所有功能模組存放於此。每個子資料夾代表一個獨立模組（例如 modules/clock/）。

locales/

全域語言翻譯檔（en_US.json, zh_TW.json 等）。

ui.py

主視窗框架與模組載入邏輯的核心程式碼。

tools/

包含建置安裝檔 (generate_nsis.py) 與套件管理腳本。

3. 模組開發

FlexiTools 的核心是模組化。請參考 modules/template_module 作為範本。

Step 1: 建立目錄與 Manifest

在 modules/ 下建立新資料夾（例如 my_tool），並新增 manifest.json：

{ "name": "my_tool", "version": "1.0.0", "title": "My Awesome Tool", "description": "A brief description of what this tool does.", "author": "Your Name" }
Step 2: 繼承 Module 類別

建立 __init__.py 並繼承基礎類別。這是模組的入口點。

from ui import Module import tkinter as tk from tkinter import ttk class MyToolModule(Module): def __init__(self, master, shared_state, module_name="MyTool", gui_manager=None): super().__init__(master, shared_state, module_name, gui_manager) self.create_ui() self.update_language() def create_ui(self): # 在 self.frame 中建立 UI self.label = ttk.Label(self.frame, text="Hello World") self.label.pack(pady=20)

4. 多語言支援

我們採用 "Develop First, Localize Later" 的策略。請勿在程式碼中寫死字串。

實作流程
  1. 在開發初期，直接在程式碼中使用英文。
  2. 開發完成後，找出所有顯示給使用者的字串。
  3. 在 locales/en_US.json 與 zh_TW.json 中新增對應的 Key。
    命名建議：module_模組名_元件_描述
  4. 將程式碼中的字串替換為 self.tr("KEY", "Default Text")。
  5. 實作 update_language() 方法以支援即時語言切換。
def update_language(self): super().update_language() # 更新視窗標題 # Guard Clause: 確保 UI 已建立 if not getattr(self, 'label', None): return # 更新元件文字 self.label.config(text=self.tr("module_mytool_hello", "Hello World"))

5. 建置與打包

若需產生 Windows 安裝檔 (.exe)，請遵循以下步驟：

需要安裝 NSIS (Nullsoft Scriptable Install System) 才能進行打包。
  • 步驟 1： 使用 PyInstaller 打包主程式。
    pyinstaller main.spec
  • 步驟 2： 生成 NSIS 腳本。此腳本會自動掃描 modules/ 並加入安裝清單。
    python tools/generate_nsis.py
  • 步驟 3： 編譯安裝檔。
    makensis installer.nsi
